# Diabetes_Dataset_EDA
Diabetes Dataset EDA

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the Diabetes Dataset using Python and data analysis libraries such as Pandas, Matplotlib, and Seaborn. The goal is to understand the structure of the dataset, identify patterns and relationships between variables, and extract meaningful insights related to diabetes prediction.

## Objectives
- Load and explore the dataset
- Clean and inspect the data
- Perform statistical analysis
- Visualize relationships between features
- Identify key factors associated with diabetes outcome

## Dataset
Diabetes Dataset from Kaggle:  
https://www.kaggle.com/datasets/akshaydattatraykhare/diabetes-dataset

## Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Kaggle Notebook

## Exploratory Data Analysis Performed
- Dataset inspection
- Missing value checks
- Duplicate value checks
- Statistical summary
- Correlation analysis
- Heatmaps
- Histograms
- Boxplots
- Scatterplots

## Key Insight
The analysis revealed that glucose level has the strongest positive correlation with diabetes outcome, indicating that higher glucose levels are strongly associated with diabetic patients.
